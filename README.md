## Tycoon

Попытка в создание игры в середине второго курса. 
Для начала хотел перенести карточную мини-игру из персоны 5, 
но некоторый правила немного переделал, чтобы было легче писать.

---
Имеет простой UI, с основными для игры полем, двумя таблицами с картами в руке и готовыми для того, чтобы лечь на поле.
Для управления игрой есть кнопки: Начать игру, выбрать карту(подготовить для того, чтобы выложить), положить на стол, пас.
